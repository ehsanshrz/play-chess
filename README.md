# Play Chess

A responsive chess game against a browser-based opponent. The game supports legal moves, castling, en passant, pawn promotion, checkmate, and stalemate.

Open `index.html` in a browser to play, or serve this directory locally:

```sh
python3 -m http.server 8000
```

Choose a side, start a new game, and use Undo to take back the last turn. Use the language button to switch between English and فارسی; the Persian interface uses right-to-left layout.
